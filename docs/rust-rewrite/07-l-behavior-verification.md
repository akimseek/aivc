# L 行为层核对清单（L1–L20）

> **这是唯一必须用眼睛的部分。**
>
> 接口层已完成机械核对（见 `06-l-audit-frontend-vs-bridge.md`），但**接口存在不等于行为正确**。
> 本工程已证明这一点：7 个缺陷全是「真跑 + 看界面」暴露的，没有一个是接口审计能发现的。
>
> 用法：按顺序操作，把**不符合预期**的条目编号告诉我。每条都写明了「背后是哪条命令」——
> 这样失败时能直接定位到层级。

## 事先说明：验证环境

```
D:\code\ai\aivc-rs\target\debug\aivc-app.exe
```

启动后会有**黑色控制台**（后端日志）。若某项失败，日志在：

```
<运行根>\logs\app.log            后端
<运行根>\logs\performance.log    前端动作与异常
```

**运行根 = 启动时的工作目录。** 从 `target\debug\` 启动就是该目录。

---

## 一、布局与外壳（L1、L7、L18、L19）

### L1 布局

**操作**：启动后观察主界面。
**预期**：
- 顶部菜单栏、左侧栏、中间终端工作区、底部状态栏，四块齐全
- 侧栏宽度约 **360px**
- 把窗口拖到很小，**最小尺寸停在 980×640**，不能再小

**背后**：窗口配置（`tauri.conf.json`），非命令。

### L7 状态栏

**操作**：看底部状态栏，然后**把窗口拖窄**。
**预期**：
- 状态栏有「会话 / 目录 / 供应商 / 用量」分组
- 窗口变窄时**低优先级分组隐藏**（不是换行、不是溢出）

### L18 设计 token 与按钮

**操作**：看任意按钮、图标按钮、对话框。
**预期**：
- 主/次按钮三态（常态 / hover / disabled）视觉一致
- **纯图标按钮只有一种实现**
- 对话框的关闭按钮**在标题栏右上角**（不是别处）

### L19 图标

**操作**：鼠标悬停到任意图标按钮上。
**预期**：出现 tooltip（`title`）；图标风格统一（Lucide）。

---

## 二、侧栏与会话列表（L2、L3）

### L2 侧栏层级

**操作**：看侧栏一级/二级；选一个没有回收站的目标。
**预期**：
- 一级「工作台 / 会话」
- 二级「当前会话 / 收藏夹 / 回收站」
- **回收站固定显示**，不可用时是**禁用态 + tooltip 说明**（不是消失）

**背后**：`codex:list-trash-sessions`

### L3 收藏/最近区高度

**操作**：在收藏夹与最近区之间切换，观察高度变化。
**预期**：区域高度由 `max-height` 控制，**不随窗口高度按百分比拉伸**。

---

## 三、工作台（L4、L5、L6）

### L4 指标卡

**操作**：切到工作台。
**预期**：
- **2×2 指标卡** + 速率限制窗口 + 今日用量 + **最近异常 3 条**
- 点诊断能看到弹窗

**背后**：`gateway:get-usage-summary`、`gateway:get-recent-failures`、`gateway:get-vendor-health`、`gateway:get-failure-diagnostics`

### L5 工作台不轮询（**重点**）

**操作**：停在工作台，**什么都不做，观察 30 秒**。然后看运行根下的 `logs/app.log`。
**预期**：
- 界面数字**不自己跳动**（没有轮询）
- 日志里**没有周期性重复的命令**（不该每几秒出现一次相同的 `command="gateway:..."`）
- 但**新发起一次网关请求后**，数字应当**自动更新**（靠 `gateway:request-recorded` 事件）

**背后**：事件推送 + 桥的 `onGatewayRequestRecorded`。这是本轮刚接通的能力，**最值得验证**。

### L6 当前供应商

**操作**：在供应商页配置一条「按标签路由」的映射，回工作台看「当前供应商」。
**预期**：显示的是**按标签路由映射**得到的结果，**不是候选池第一项**。

**背后**：`vendor:route-switch` / `vendor:route-mode`

---

## 四、终端交互（L8–L12）

### L8 标签保存目标快照

**操作**：开一个终端标签，然后**在左侧把目标切换成另一个**。
**预期**：**已有标签不受影响**（它保存的是创建时的完整目标快照，不从左侧列表反推）。

### L9 标签同步只更新内存

**操作**：切换标签，观察 `logs/app.log`。
**预期**：**日志里不出现** `codex:list-targets` / `list-cached-targets` / 会话扫描——
标签同步只改内存，**不触发探测**。

### L10 自管输入（**逐项**）

**操作**：在终端输入框里依次试：
1. 切换模型选择
2. 添加附件
3. `Alt+Enter` 换行
4. 用中文输入法打字，**在拼音未上屏时按 Enter**
5. 粘贴一大段文本（含换行）

**预期**：
1. 模型切换生效
2. 附件可加
3. `Alt+Enter` 是多行，**普通 Enter 是提交**
4. **IME 组合态的 Enter 不提交**（只上屏候选）
5. 括号粘贴被**合并成一次写入**（Qoder 除外）

**背后**：`terminal:write`（第 5 项与写入合并有关）

### L11 焦点

**操作**：切换标签、显式点输入框、切换输入模式。
**预期**：焦点**只在这三种情况**变化；不该出现「焦点莫名跳走」。

### L12 终端搜索/复制/粘贴/右键菜单

**操作**：在终端里选中文字 → 右键；试复制、粘贴、搜索。
**预期**：
- 右键菜单只有**复制 / 粘贴**两项
- 复制、粘贴可用，终端搜索可用

**⚠️ 已知缺口**：`clipboard:copy-text` / `clipboard:read-text` **未接线**（离线缺依赖）。
**如果复制/粘贴无效，这是已知原因，不用报。**

---

## 五、会话详情与检索（L13、L14）

### L13 会话详情

**操作**：打开一个长会话，向上滚动加载更多，然后点某条消息的「分支」入口。
**预期**：
- 首屏**定位在末尾**
- 向上加载时**阅读位置保持**（不跳到顶部）
- 分支入口可用

**背后**：`codex:get-session-messages-page`、`codex:branch-session`

### L14 全局检索

**操作**：在检索框里快速连续输入，然后改筛选条件。
**预期**：
- 输入**防抖 250ms**（不是每敲一个字母就查）
- 改筛选/继续输入时，**过期结果不覆盖新结果**
- 跨目标检索结果**带目标快照**（点进去落到正确的目标）

**背后**：`codex:search-sessions`

---

## 六、供应商表格（L15）

### L15

**操作**：在供应商页试：拖列宽、翻页、开/关候选池、刷新余额、打开故障规则弹框。
**预期**：五者都可用；故障规则是**独立弹框**（不是内嵌展开）。

**背后**：`vendor:*` 系列。
**⚠️ 已知缺口**：`refreshVendorBalance` 需要某些供应商的**响应模板**，可能显示失败——
失败时请把**错误文案**告诉我。

---

## 七、命令面板与提醒中心（L16、L17）

### L16 命令面板

**操作**：按 `Ctrl+K`（macOS 是 `Cmd+K`）打开，试几条命令。
**预期**：
- 面板列出**与菜单相同的 action**（递归复用，不是另一套）
- **在原生终端输入模式下 `Ctrl+K` 不被拦截**（该模式要真的进终端）

### L17 提醒中心

**操作**：触发一次终端提醒（需要终端输出提示），然后：
1. 点铃铛展开
2. 点某条提醒
3. 点某条的 `X`
4. 全部移除

**预期**：
1. 展开列表
2. **切到对应标签并标已读**
3. **该条真正移除**（不是只隐藏）
4. 全移除后**入口本身卸载**

**⚠️ 已知缺口**：`terminal:attention-notification` **未接线**（离线缺系统通知依赖）。
**如果铃铛压根不出现，这是已知原因。**

---

## 八、分页组件（L20）

### L20

**操作**：在任意带分页的表格上试：切 10/20/50、跳首页/末页、点页码。
**预期**：默认 **10**，上限 **50**，有首页/末页/页码窗口，键盘可访问。
